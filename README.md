# Siddique Ahmed Alvi - Portfolio

Official portfolio website for Siddique Ahmed Alvi, Emerging Motivational Speaker and Personality Grooming Trainer.

## Features
- **Modern Hero Section**: "Dhar Mann" style layout with bold typography.
- **About & Services**: specialized sections for speaking and training services.
- **Contact Form**: easy way to book sessions.
- **Responsive Design**: works on all devices.

## Tech Stack
- HTML, CSS, Vanilla JavaScript
- Vite

## How to Run locally
1. Clone the repo: `git clone https://github.com/WaseemAkramAlvi/Siddique_Ahmed_Alvi.git`
2. Install dependencies: `npm install`
3. Run dev server: `npm run dev`
